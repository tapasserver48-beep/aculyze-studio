Send (or Replay) runs the fake flow: idle → thinking (rotating labels + live timer + steps) → streaming (collapses to “Thought for Ns”) → done (expandable). Stop during thinking cancels. Reduced-motion is respected automatically.

Usage notes

  • status — idle hides everything; thinking shows the live indicator; streaming collapses it to “Thought for Ns”; done keeps that row expandable.
  • statusLabels — array of lines that rotate every 2.5 s with a fade (aria-live="polite").
  • steps — {id, text} items appended over time; each animates in once.
  • elapsedSeconds — omit to let the component run its own clock (freezes when leaving thinking); pass a number to display a host-controlled time instead.
  • onCancel — fired by the Stop button (visible only while thinking).
  • A11y: aria-busy on the root, focusable native buttons for expand/collapse (Enter/Space), prefers-reduced-motion swaps animations for a static indicator.
  • Theme: all colors come from CSS variables (host --accent, --text-muted, --border, --surface are picked up automatically; sensible light/dark fallbacks otherwise).
import { createThinking } from './thinking.js';

const t = createThinking({
  status: 'thinking',
  statusLabels: ['Reading your message', 'Gathering context', 'Drafting a reply'],
  steps: [{ id: 's1', text: 'Reading your message' }],
  onCancel: () => controller.abort(),
});
mount.appendChild(t.el);

t.update({ steps: [...steps, { id: 's2', text: 'Searching the web' }] });
t.update({ status: 'streaming' });  // collapses → "Thought for Ns"
t.update({ status: 'done' });       // row stays, expandable

const { seconds, steps } = t.snapshot();  // persist with the message
t.destroy();
